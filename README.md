# ⌨️ Jogo de Digitação – Projeto ADS

Aplicação desenvolvida como projeto acadêmico no curso de **Análise e Desenvolvimento de Sistemas (UNICID)** para praticar lógica de programação, manipulação de strings, persistência de dados e organização modular de código.

## 🎯 Objetivo do Projeto
Criar um sistema interativo para treinar a velocidade e a precisão de digitação, registrando o desempenho dos usuários e ordenando o ranking de pontuação de forma estruturada.

## ⚙️ Funcionalidades
* **Teste de Digitação:** Exibição de palavras e frases com medição de tempo e precisão de acertos.
* **Sistema de Pontuação e Ranking:** Cálculo automático de desempenho e exibição dos melhores resultados utilizando algoritmos de ordenação.
* **Persistência de Dados:** Leitura e gravação do histórico de partidas e pontuações em arquivos estruturados (`.csv`).
* **Estrutura Modular:** Separação clara de responsabilidades entre entrada de dados, regras de negócio e armazenamento.

## 🛠️ Tecnologias e Conceitos Aplicados
* **Linguagens:** Linguagem C / JavaScript
* **Estruturas e Lógica:** Manipulação de strings e buffers, algoritmos de ordenação e modularização
* **Persistência:** Manipulação de arquivos de texto e formato CSV
* **Ferramentas:** VS Code, Git e GitHub
